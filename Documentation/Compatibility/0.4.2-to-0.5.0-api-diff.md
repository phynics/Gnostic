# API diff: 0.4.2 to 0.5.0

**Status: informational, not a gate.** This record lists the source-breaking
public API changes between 0.4.2 and the 0.5.0 development line. 0.5.0 breaks
0.4.2 on purpose ([0.5.0](0.5.0.md), ADR 0021), so this diff cannot gate. The
gate is the baseline in [`API/`](API/README.md), which starts at 0.5.0.

## How it was produced

0.4.2 had one library product that consumers could build against,
`GnosticCore`. It had no `GnosticProtocol` or `GnosticClient` product. The list
comes from the SwiftPM comparison of that product at the `0.4.2` tag with the
same product at main (`1db7abc`, after #714):

```sh
swift package diagnose-api-breaking-changes 0.4.2 --products GnosticCore
```

The command ran in the pinned development container from a standalone clone, on
Swift 6.4. SwiftPM printed 183 breaking changes in `GnosticCore`. The list
below is that output, with its source locations and the build log removed.

## Read the list with these limits

- It covers `GnosticCore` only. Types that moved to `GnosticProtocol` (for
  example `NetworkCatalogChange` and `TimelineStatus`)
  count as "removed" here, because the tool matches by module. `import
  GnosticCore` still re-exports them. The migration tables in
  [0.5.0](0.5.0.md#migration-notes-for-swift-consumers) list each rename and move.
- It lists removals and changes. It does not list API that 0.5.0 adds.
- A line that mentions an `Ascendant` type belongs to the Ascendant to Turn and
  Runtime instance rename (#675) or to the removed in-process backends.
- The `GnosticPositronicAtlas` and `GnosticRLM` libraries of 0.4.2 are not
  compared. They are experiments and are not stable products.
